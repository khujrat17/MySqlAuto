# 📦 MySqlAuto

**Automated MySQL Backup & Restore Tool**

MySqlAuto is a simple utility designed to help developers **take backups and restore MySQL databases automatically**, reducing manual effort and risk of data loss.

---

## 🚀 Features

- 🔄 Automatic MySQL database backup  
- ♻️ Easy database restore from `.sql` files  
- ⚙️ Simple configuration  
- 💻 Suitable for local and remote MySQL servers  

---

## 🛠️ Tech Stack

- MySQL  
- .NET / Scripts  
- JavaScript (as per repository usage)
